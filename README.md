# 线代练习室 · Linear Algebra Lab

42 道中英双语模拟练习题，支持选择、填空、连线、逐题判分与解析、错题重练和浏览器进度保存。

网页入口：`index.html`，无需构建或安装依赖。答题记录保存在每位访客自己的浏览器中。

## 启用公开网站

在 Settings → Pages → Build and deployment 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

点击 Save，等待 Pages 部署成功。公开地址以 Settings → Pages 显示的链接为准。

## 内容范围

根据线性代数教材第 1–4 章和 Tut 1–3 原创或改编的练习题，参考期末试卷的概念辨析与计算难度。仓库不包含教材照片、PDF 试卷或账号凭据。
